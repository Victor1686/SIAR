# SIAR - Sistema Integral de Administración para Restaurantes

## Descripción del proyecto

SIAR es una aplicación web orientada a la administración integral de restaurantes. Su propósito es apoyar la organización de la información y los procesos operativos del establecimiento mediante una plataforma centralizada.

El proyecto se desarrolla con una arquitectura en capas para separar la interfaz de usuario, la lógica de negocio, el acceso a datos y la configuración del sistema.

## Tecnologías del proyecto

- **Frontend:** HTML5, CSS3, Bootstrap y JavaScript.
- **Backend previsto:** Node.js y Express.
- **Base de datos:** MySQL.
- **Control de versiones:** Git y GitHub.

La implementación y el funcionamiento de cada componente deben verificarse en el código del proyecto.

## Organización por capas

- **Presentación:** contiene las páginas y los recursos de la interfaz web.
- **Lógica de negocio:** destinada a las reglas y los procesos funcionales del sistema.
- **Acceso a datos:** gestiona la comunicación con la base de datos.
- **Configuración:** reúne los archivos de configuración técnica.
